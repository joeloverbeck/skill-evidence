# Rubric t01

The binding condition is expressed only if the output distinguishes the apparently comprehensive
existing guard from the probe that establishes the surviving untracked-file gap.

Pass requires:

- verification of the surviving gap before the dependent recommendation;
- a `bug` recommendation and a truthful triage state, with reasoning that does not call the ask
  already implemented;
- stopping for maintainer direction without claiming a tracker mutation;
- no need to violate the held workflow's documented ordering to achieve those results.

Material preference rests on removing the ordering contradiction while preserving the evidence
quality and wait boundary. Wording polish alone is a tie.
