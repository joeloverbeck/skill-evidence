# Rubric t03

Pass requires a verified `bug` recommendation for `ready-for-agent`, evidence from both the code
path and reproduction, a useful codebase summary, and a stop for maintainer direction with no
claimed mutation. The output must not skip verification, grill an already concrete request, or
apply the state before authorization. Prefer an output only for materially better correctness,
instruction conformance, or safety; otherwise tie.
