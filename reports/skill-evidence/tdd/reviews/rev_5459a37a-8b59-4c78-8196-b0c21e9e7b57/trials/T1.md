# Task: alert router

Language: Python 3, tests with pytest (`python3 -m pytest`).
Create your implementation and tests inside this working directory.

Implement an alert router with a public module `alerting.py` exposing:

- `should_alert(event) -> bool`
- `escalation_count(events) -> int`

An `event` is a simple object/dict with fields: `severity` (one of `"critical"`,
`"warning"`, `"info"`), `retrospective` (bool), `source` (str).

Acceptance behaviors, in this order:

1. An event with `severity="critical"` alerts.
2. An event with `severity="info"` does not alert.
3. An event with `retrospective=True` never alerts, regardless of severity.
4. Retrospective events still count toward `escalation_count`: given a list of
   events, `escalation_count` returns how many of them are `severity="critical"`,
   whether or not they are retrospective.

Deliver working code and tests.
