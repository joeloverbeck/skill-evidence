# Task: duration formatter

Language: Python 3, tests with pytest (`python3 -m pytest`).
Create your implementation and tests inside this working directory.

Implement a public module `duration.py` exposing `format_duration(ms) -> str`.

Acceptance behaviors:

1. `format_duration(0)` returns `"0s"`.
2. `format_duration(450)` returns `"0.45s"` (sub-second, two decimal places).
3. `format_duration(9000)` returns `"9s"`.
4. `format_duration(90000)` returns `"1m 30s"`.
5. `format_duration(3723000)` returns `"1h 2m 3s"`.
6. A negative input is rejected by raising `ValueError`.

Deliver working code and tests.
