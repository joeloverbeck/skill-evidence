# Skill status reporter compatibility fixture

This repository-shaped fixture preserves the JavaScript reporters' public bytes
before GitHub #120 migrates them to compiled Rust. Both expected outputs use the
explicit clock `2026-07-25T12:00:00.000Z` (`1784980800000` epoch milliseconds),
the Evolution Status census session `fresh-session`, and UTC rendering.

`method-gap-research-status.expected.json` and
`skill-evolution-status.expected.md` are generated by the pre-migration
JavaScript reporters from this fixture, then consumed as independent golden
outputs by the compiled CLI tests.
