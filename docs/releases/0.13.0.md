# skill-evidence 0.13.0

This release requires a minor version bump from `0.12.x` to `0.13.0` because it changes the bytes of the live installed `skill-evolution` package.

## Installed-package change

The authorized-review procedure now:

- admits a natural observable only when the run's own outputs and frozen inputs carry it;
- treats an unretainable observable as a plan defect that voids only its clause reading, without an unable-to-be-expressed or instrument-limited consequence;
- records a reading unread when its named artifact is absent, never substitutes a proxy, and prevents an unread reproduction reading from authorizing a candidate; and
- restates a frozen mechanism clause or observable verbatim in the terminal report, or omits the restatement.

No package is added, retired, or renamed.

## Rust API and command behavior

- The non-exhaustive `Recovery` enum adds `ReleaseEvidenceLock` so hosts can give operators a specific recovery instruction after an evidence-lock refusal.
- A lock-acquisition refusal now identifies the current holder and its start time when that ownership metadata is available.
- Existing commands, flags, and exit meanings are unchanged.

## Recorded evidence and schemas

Recorded-event serialization now dispatches through one event-type-owned seam, with exact-byte and validated-key custody for every writable event type. Published schema bytes, recorded-event shape, and existing event bytes are unchanged.

## Consumer upgrade

After updating the crate dependency, each consumer must reinstall the changed package explicitly:

```console
cargo update -p skill-evidence
<host-command> skills evidence install --root .
<host-command> skills evidence install --root . --force
```

The unforced install is expected to refuse atomically with exit `3` when it finds the older installed package bytes. Read and confirm its differing-file list before running the required `skills evidence install --force` step.

Release verification included the complete locked Cargo release gate and representative forward tests of the changed installed package in fresh Codex and Claude sessions.
